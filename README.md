# Python-Vision

Welcome to my Computer Vision learning journey! This repository contains my practice projects using Python and OpenCV during my freshman year.

## 🚀 Projects Overview

*   **`first_vision.py`**: Read an image from the local directory and display it using OpenCV.
*   **`image_process.py`**: Basic image processing including converting to grayscale and edge detection (Canny algorithm).
*   **`camera_test.py`**: Real-time video capture using the webcam, applying a real-time grayscale filter.
*   **`face_detect.py`**: Real-time face detection using Haar Cascades. Draws green bounding boxes around detected faces.

## 🛠️ Technologies Used
*   Python 3
*   OpenCV (cv2)

## 🎯 Future Goals
*   Learn more advanced image processing techniques (like contour detection, image filtering).
*   Transition from traditional Haar Cascades to Deep Learning-based models (like YOLO).
